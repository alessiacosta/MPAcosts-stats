# Code supporting the paper titled "The costs of establishing and maintaining marine protected areas: a global meta-analysis"

## The code
"MPAcosts-stats" contains the scripts, data, and results that were used to conduct statistical analysis to estimate the establishment and maintenance costs of Marine Protected Areas (MPAs). This meta-analysis collects all cost estimates available in the literature for MPAs and MPA networks worldwide. This R project contains: 
1. A folder titled "codes" that contains scripts used for the analyses
  - Ch3-MPAcosts.qmd <- Regression analysis in a Bayesian framework and script to produce figure 1 and result summary figures
  - additional.figures.qmd <- Script to reproduce figures 2 and 4 (establishment costs vs GDP per capita - univariate model and summary figure included here)
  - t-test.qmd <- code with t-test used to compare the difference in strength between the estimates produced in this model and models from previous papers
2. A folder titled "Data" with the data used for the analyses
3. A folder titled "Results" with the figures produced from the analyses results
